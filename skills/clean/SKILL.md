审阅项目中所有 AGENTS.md，精简到只留精华。

AGENTS.md 是**协作契约**，不是知识库。每一行都要赢得自己的位置：
agent 不能靠读代码库推断出它，且它必须每个会话都成立。

## 该移除什么

- agent 读代码库或标准文档即可推断的**显然事实**
- "写干净代码"、"遵循最佳实践"之类的**空泛原则**
- **冗长解释**——每条洞见压缩到 1-3 行直接陈述
- 父级 AGENTS.md 已声明的**重复内容**（子级继承父级）
- **低频任务知识** → 标记迁移到 Skill
- **完整 API 文档、背景介绍、历史沿革** → 标记迁移到 Skill
- 已不再成立的**过期规则**

## 该保留什么

只保留同时满足：
- 无法通过读代码库发现
- 每个会话都成立（非情境性的）
- 可执行（具体命令、约束、规则）

## 重组

如果 AGENTS.md 缺少清晰章节，重组为：

```markdown
# 项目协作契约

## 构建与测试

## 架构边界

## 编码约定

## 安全护栏
### 禁止（NEVER）
### 必须（ALWAYS）

## 验证
```

相近条目合并到对应章节。清空后剩下的章节直接移除。

## 流程

1. 找到并读取项目中所有 AGENTS.md（`find . -name AGENTS.md`）
2. 对每条内容做判定："agent 能从代码推断吗？它每会话都成立吗？"
3. 不合格的移除；冗长的压缩到 1-3 行
4. 清除父/子 AGENTS.md 之间的重复（子级只写与父级不同的部分）
5. 标记应迁往 Skill 的条目
6. 将剩余内容重组到标准章节

完成后总结：
- 修改了哪些文件
- 移除的条目（按原因分组）
- 压缩的条目
- 建议迁移到 Skill 的条目
